# Changelog

## 0.1.0

- Independent Python library, CLI and localhost browser demonstration.
- Internal-first, curated-source retrieval with source-owned citations and versioned JSON schemas.
- Color-linked paragraphs and recommendation cards, with numbered labels and source views.
- Manual recommendation button and opt-in timed checks with stale-result and overlap protection.
- Explicit citation copy/insertion, Markdown download, filters and dismiss/restore actions.
- One optional local Ollama assessment skill; no model downloads or open-web discovery.
- Synthetic internal examples, curated NIST excerpts, contribution and integration guides.
